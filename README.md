# Job Finder Rwanda

Connecting talent with opportunity across the land of a thousand hills.

Job Finder Rwanda is a streamlined job search and recruitment platform designed specifically for the Rwandan job market. Whether you're a fresh graduate looking for your first role, an experienced professional seeking new challenges, or an employer wanting to reach top local talent—this platform brings opportunities and people together.

## Features

- **Smart Job Search** – Filter by category, location (Kigali, Musanze, Huye, etc.), experience level, and employment type.
- **Employer Dashboard** – Post openings, manage applications, and track candidates with ease.
- **Candidate Profiles** – Build detailed profiles, upload CVs, and highlight key skills.
- **Application Tracking** – Real‑time status updates for applicants (submitted, reviewed, interview, offer).
- **Saved Searches & Alerts** – Get email notifications when new jobs match your preferences.
- **Responsive Design** – Works seamlessly on desktop, tablet, and mobile devices.
- **Rwandan Focus** – Localised job categories (e.g., ICT, agribusiness, tourism, public service) and salary ranges in RWF.

## 🛠️ Tech Stack

- **Frontend** – React (Vite) + Tailwind CSS  
- **Backend** – Node.js + Express  
- **Database** – PostgreSQL (or MongoDB, adjust as needed)  
- **Authentication** – JWT + bcrypt  
- **Email Service** – Nodemailer (or SendGrid)  
- **Deployment** – Docker + AWS (or Vercel + Railway)
